# Akinwumi (2015) — Beneficiation of Nigeria Local Clay to Meet API Standard Specification for Drilling Fluid Formulation (A Case Study of Abbi Clay Deposit, Delta State)

**Full citation:** Akinwumi, A. (2015). "Beneficiation of Nigeria local clay to meet API standard specification for drilling fluid formulation. (A case study of Abbi clay deposit, Delta State)." *International Journal of Engineering Sciences & Management (IJESM)*, 5(3), 16–28. ISSN: 2277-5528. Author affiliated with Federal University of Petroleum Resources, Effurun, Delta State, Nigeria.

**Deposit/location:** Abbi town, Ndokwa West Local Government Area, Delta State, Nigeria. Stated coordinates: "Latitude 6.45°E and Longitude 5.30°N" — **this labeling is almost certainly swapped/erroneous** (Delta State, Nigeria sits at roughly 5–6°N latitude and 5–6°E longitude; the paper's own numbers are plausible in magnitude but mislabeled which axis is which). This is the same type of coordinate-transcription error already flagged in your Alshameri (2013) summary — worth noting as a recurring, cross-paper pattern of unreliable printed coordinates that you cannot take at face value without independent verification.

**⚠️ Possible identity overlap with a citation in your other sources:** Both Khan (2017)'s reference list and Afolabi et al. (2017)'s review cite a **"Wilfred, O.C. & Akinade, A.E. (2016)"** and an **"Akinade, A. & Afolabi, F. (2015a,b)"** paper on this exact same deposit (Abbi clay, Delta State). This single-author 2015 paper is authored by "Akinade Akinwumi" — plausibly the same individual as "Akinade, A." in those other citations (name-ordering/formatting inconsistency between sources is common in Nigerian engineering-journal citations). **Worth flagging but not fully resolving here** — if you cite this paper and also encounter "Akinade & Afolabi (2015a/b)" or "Wilfred & Akinade (2016)" elsewhere, check they aren't the same underlying study before double-counting it as independent corroboration.

**Method:** Sample collected ~5 ft depth from Abbi locality → dried, pulverized, sieved → mud preparation at three concentrations (17.5, 21.0, 24.5 g clay/350 mL water), aged 24 h → rheological/physical testing (OFITE Model 900 viscometer: PV, AV, YP, gel strength; mud balance density; pH via phydrion paper; API sand-content test; power-law index "n" and consistency index "K") per API RP-13B procedures, on raw local mud **and** in parallel on a "foreign Bentonite" reference mud, both before and after beneficiation with **1.0 g Drispac + 1.0 g potash** (fixed single dose, no dosing sweep) → benchmarked against an API specification table (Table 3.0) reproduced in the paper.

---

## Important limitation up front: no mineralogical characterization at all

Unlike essentially every other source in your reference base (Alshameri, Hassan, El-Mahllawy, Khan, Magzoub, Afolabi review), **this paper contains zero XRD, XRF, CEC, or any other mineralogical/chemical characterization of the Abbi clay.** There is no Na/Ca ratio, no basal-spacing data, no oxide composition — the Ca-dominant/low-quality-raw-material narrative here is **inferred entirely from the clay's poor initial rheological/pH performance**, not demonstrated via any compositional evidence. This makes it a weaker addition to your "independent mineralogical evidence of Ca-dominance across many deposits" argument than your other sources — it's useful only for the rheology/beneficiation-outcome side of your narrative, not the mineralogical side.

## Key findings

**API specification table reproduced in the paper (Table 3.0) — treat with caution:** The paper's own reproduction of "API practices 13A section 5" contains what look like internal inconsistencies and likely transcription errors:
- States **"Fluid loss (Water) 15.0 mL maximum"** (consistent with the verified Table 8 bentonite spec from your primary API 13A source) but *also* separately states **"API filtrate (ml) 30 (minimum)"** a few rows later — these two rows are contradictory/nonsensical together and cannot both be correct filtrate specifications. This is almost certainly a table-transcription error in the original paper (possibly conflating filtrate volume with an unrelated dial-reading-style "minimum" value), **not a genuine third alternate filtrate-limit citation** — don't add this "30 mL" figure to your API/OCMA filtrate-discrepancy discussion; it doesn't read as a real competing claim, just an error.
- The table also lists what appear to be **CEC ranges for generic clay-mineral groups mislabeled as an API drilling-mud requirement**: "Montmorillonite 70–130, Vermiculite 100–200, Illite 10–40, Kaolinite 3–15, Chlorite 10–40" — these numbers correspond closely to well-known **cation exchange capacity (CEC, meq/100g) ranges for these mineral groups** in general clay-science references (e.g., Grim's classic CEC ranges), not to any specification API 13A actually imposes on drilling-mud material composition. This looks like a separate reference table that got merged into the "API standard" table during the paper's writing — **do not cite this row as an actual API requirement.**
- Other rows in the same table (mud density 8.65–9.60 lb/gal; dial reading @600 rpm minimum 30; YP/PV ratio maximum 3; pH 9.5–12.5; sand content 1–2% maximum) are consistent with standard API 13A/RP-13B drilling-fluid practice and can be cited with more confidence.

**Rheological results (Tables 4.0–4.6) — clear before/after pattern:**

|---|---|---|---|---|
| Mud weight (lb/gal) | 8.60 | 8.70–8.90 | 8.60–8.70 | 8.65 min |
| pH | 6.0 (acidic) | 9.0 | 12.0 | 9.5–12.5 |

**⚠️ Data inconsistency worth flagging — different "foreign Bentonite" values appear in different tables:** Table 4.2 ("Result of Bentonite mud without beneficiation") reports **much higher** viscometer readings for the foreign bentonite reference (θ600 = 246.1, 287.2, 300.0 cp; PV up to 127 cp; YP up to 66.7 lb/100ft²) than the values used as the "Foreign mud" comparator in the summary Tables 4.4–4.6 (17.0–31.4 cp). **These two datasets cannot both describe the same reference material at the same concentrations** — this is either a units/labeling mix-up (possibly Table 4.2's high values are from a much higher clay concentration, or from a different/more concentrated commercial mud formulation, not directly comparable to the 17.5–24.5 g/350 mL local-clay concentrations) or a genuine data-entry error in the paper. **Recommend using only the values explicitly paired in the direct comparison tables (4.4–4.6: 17.0, 21.1, 31.4 cp) if you cite this paper's "foreign mud" benchmark, and flag Table 4.2's numbers as unreliable/unreconciled** rather than trying to cite both.

**Core narrative (Conclusion):** Raw Abbi clay met API minimum requirements for **sand content and power-law index "n"** even before treatment, but failed on **viscosity (dial reading), pH, and mud weight**. A single fixed dose of 1.0 g Drispac (polyanionic cellulose polymer) + 1.0 g potash (likely a K-based pH raiser, possibly K₂CO₃) brought viscosity, pH, and mud weight into compliance across all three tested concentrations. No dosing sweep was performed — this is a single-point OFAT test, even more minimal than the OFAT designs in your other sources (which at least varied additive dose across several levels).

## Numbers worth citing directly

- Raw Abbi mud viscometer dial reading @600 rpm: 1.70–2.70 cp (vs. API min 30) — a very large initial deficiency
- Raw Abbi mud pH: 6.0 (acidic) vs. API required range 9.5–12.5
- After 1.0 g Drispac + 1.0 g potash: dial reading rose to 33.0–35.5 cp; pH rose to 12.0 — both within/above API spec
- Sand content and power-law index "n" met API spec even in raw, untreated clay
- Single fixed additive dose used (1.0 g Drispac + 1.0 g potash per 350 mL) — no dosing sweep, no DOE

## Relevance to this thesis

- **Chapter 1 (balanced risk framing):** consistent with the "quantify the shortfall, then show partial-to-full success after minimal treatment" narrative you've already built using Magzoub (2014), Hassan (1998), and El-Mahllawy (2013) — this is a useful, low-cost precedent showing that even a **single small fixed dose** of two common additives (not even a full activation protocol) was sufficient to bring three of the most commonly-failing parameters (viscosity, pH, mud weight) into API compliance. Useful as a "floor" case for how little treatment intensity might be needed in a best-case scenario, worth contrasting against your Box-Behnken design's higher rigor.
- **Chapter 1/3 (methodological caveat-building):** the internal inconsistencies in this paper's own "API standard" table (contradictory filtrate figures, mislabeled CEC-range row) reinforce the broader pattern already established across your reference base — that secondary sources frequently mis-transcribe or conflate standard values, and that you should always verify against your own primary API 13A source (already resolved in your `API_13A_13B1_summary.md`) rather than propagate any single paper's stated "API requirement" table uncritically.
- **Chapter 5 (Discussion):** useful contrast case — unlike your papers with full mineralogical workups, this one demonstrates that even *without* running XRD/CEC on the raw material, empirical rheological/pH testing alone is sufficient to identify a deficient Ca-type-behaving clay and correct it with minimal treatment; a good illustration of the "practical drilling-industry" testing approach vs. the "rigorous characterization-first" approach your own thesis takes.
- **Not usable** as mineralogical/compositional evidence — no XRD, XRF, or CEC data of any kind is reported; don't cite this paper alongside Alshameri/Hassan/El-Mahllawy as part of your "cross-regional Ca-dominant basal-spacing" argument, since it contributes nothing to that specific claim.

## Caveats / limitations

1. **No mineralogical or chemical characterization whatsoever** — this paper's entire evidentiary basis is rheological/physical testing; treat it as a rheology-only precedent, not a compositional one.
2. **The paper's own "API standard" specification table (Table 3.0) contains at least one clear internal contradiction** (two different, incompatible "filtrate" values: 15.0 mL maximum vs. 30 minimum) **and one likely mislabeled row** (CEC ranges for clay mineral groups presented as an API drilling-fluid requirement) — don't cite either without independent verification against your own primary API 13A source.
3. **Table 4.2's "foreign Bentonite" viscometer values (246–300 cp) are inconsistent with the "Foreign mud" values used in the paper's own summary comparison tables (17.0–31.4 cp)** — these cannot be reconciled from the text as given; use only the paired comparison-table values if citing this paper's commercial-bentonite benchmark, and don't cite Table 4.2's raw numbers without flagging the discrepancy.
4. Coordinates as stated in the paper ("Latitude 6.45°E, Longitude 5.30°N") have the latitude/longitude axis labels swapped — same category of error already flagged for Alshameri (2013); don't use as-is for any site-location purposes.
5. **Single fixed-dose additive test only** (1.0 g Drispac + 1.0 g potash, no dosing sweep, no DOE) — even less methodologically rigorous than the OFAT designs in your other sources; useful mainly as a "minimal treatment, still works" data point, not as a source of optimized dosing guidance.
6. Possible identity overlap with "Akinade & Afolabi (2015a/b)" and/or "Wilfred & Akinade (2016)" cited elsewhere in your reference base on the same Abbi deposit — verify before treating as fully independent corroboration if you encounter those citations directly.
